### 六、使用流程

1. **访问应用**: http://localhost:3000
2. **配置 API Key**: 点击 ⚙️ 设置 → 输入智谱 API Key → 保存
3. **开始创作**: 在对话框输入描述，例如：
   - "画一个用户登录流程图"
   - "创建微服务架构，包含 API 网关、用户服务、订单服务"
4. **编辑保存**: 手动调整画布，数据自动保存
