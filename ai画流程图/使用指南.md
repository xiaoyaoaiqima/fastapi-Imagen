## 🚀 快速开始

### 1. 访问应用

在浏览器中打开：**http://localhost:3000**

### 2. 配置 API Key

首次使用需要配置智谱 AI 的 API Key：

1. 点击右上角的 **⚙️ 设置** 按钮
2. 在设置面板中输入你的智谱 AI API Key
3. 点击 **保存配置**

**获取 API Key**：
- 访问 https://open.bigmodel.cn/
- 注册/登录账号
- 进入"API密钥"页面
- 创建新的 API 密钥

### 3. 开始使用

在右侧对话框中输入描述，例如：

```
画一个用户登录流程图
```

```
创建微服务架构，包含 API 网关、用户服务、订单服务
```

```
画一个 HTTP 请求处理流程
```

## 📊 技术架构

### 后端
- **框架**: Express + TypeScript
- **AI 服务**: 智谱 AI (GLM-4)
- **数据库**: SQLite (better-sqlite3)
- **特性**:
  - 流式响应 (SSE)
  - 用户配置管理
  - 请求日志记录

### 前端
- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **画布**: Excalidraw
- **特性**:
  - 流式 JSON 解析器
  - localStorage 持久化
  - 响应式设计

## 📝 注意事项

1. **API Key 安全**
   - API Key 存储在数据库中
   - 不要将数据库文件提交到 Git
   - 生产环境建议使用环境变量

2. **网络要求**
   - 需要访问智谱 AI API
   - 确保网络连接正常

3. **浏览器兼容**
   - 推荐使用 Chrome/Edge/Firefox 最新版本
   - 需要支持 ES2020+ 特性

## 🐛 故障排除

### 前端无法加载
- 检查端口 3000 是否被占用
- 清除浏览器缓存
- 查看浏览器控制台错误

### 后端无响应
- 检查端口 3001 是否被占用
- 查看后端日志输出
- 确认依赖已正确安装

### AI 调用失败
- 检查 API Key 是否正确
- 确认网络连接正常
- 查看智谱 AI 额度

### 数据库错误
- 检查 logs.db 文件权限
- 确认 better-sqlite3 正确安装
- 尝试删除数据库文件重新初始化
