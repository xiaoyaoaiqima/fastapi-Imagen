## 开始使用

### 1. 打开应用

在浏览器中访问：**http://localhost:3000**

你应该能看到：
- 左侧：Excalidraw 画布（白色背景）
- 右侧：AI 对话面板
- 顶部：标题栏 + 设置按钮

### 2. 配置 API Key

首次使用需要配置智谱 AI API Key：

1. 点击右上角的 **⚙️ 设置** 按钮
2. 在弹出的设置面板中：
   - 输入你的智谱 AI API Key
   - 选择模型（推荐 GLM-4-Flash，速度快）
3. 点击 **保存配置**

**获取 API Key**：
- 访问 https://open.bigmodel.cn/
- 注册/登录账号
- 进入"API密钥"或"API Keys"页面
- 创建新的 API 密钥

## 常见问题

### Q: 点击发送后一直显示"正在生成..."
**A**: 检查后端控制台是否有错误，确认 API Key 是否正确配置

### Q: AI 返回错误提示
**A**:
1. 检查 API Key 是否正确
2. 检查网络连接
3. 查看智谱 AI 额度是否用完
4. 查看后端控制台错误信息

### Q: 生成的图形显示不全或格式错误
**A**: 这是正常的，AI 可能输出格式不完美。可以：
1. 手动编辑调整
2. 重新描述需求
3. 清空画布后重新生成

### Q: 刷新页面后数据丢失
**A**:
1. 检查浏览器是否禁用 localStorage
2. 打开开发者工具 → Application → Local Storage 查看
3. 确认没有使用浏览器隐私模式

## 调试技巧

### 查看后端日志

### 查看数据库
```bash
cd backend
sqlite3 logs.db

# 查看配置
SELECT * FROM user_config;

# 查看聊天日志
SELECT * FROM chat_logs ORDER BY id DESC LIMIT 10;

# 退出
.quit
```

### 清除数据
```bash
# 清除浏览器 localStorage
# 打开开发者工具 → Application → Local Storage → 右键 → Clear

# 清除数据库
rm backend/logs.db
# 重启后端会自动创建新数据库
```
